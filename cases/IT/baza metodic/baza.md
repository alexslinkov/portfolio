Название проекта

Корпоративная RAG-система для работы с методической базой знаний

Краткое описание

Разработана локальная RAG-система (Retrieval-Augmented Generation) для поиска и генерации ответов по методическим материалам компании. Система позволяет сотрудникам задавать вопросы на естественном языке и получать ответы с точными ссылками на исходные документы.

Технологический стек

Компонент	Технология
Язык программирования	Python 3.13
Фреймворк веб-интерфейса	Streamlit
Векторная база данных	ChromaDB
LLM для генерации	Ollama (gpt-oss:20b / qwen2.5:3b)
Эмбеддинги	sentence-transformers (multilingual-e5-large)
Извлечение текста	pdfplumber, python-docx
Разбиение на чанки	LangChain
Контейнеризация	Git
Функциональность

✅ Поддержка форматов: PDF, DOCX, TXT
✅ Автоматическое извлечение текста и разбиение на семантические чанки
✅ Поиск релевантных фрагментов по векторному сходству
✅ Генерация ответов на русском языке на основе найденных документов
✅ Указание источников (имя файла + номер страницы)
✅ Веб-чат с историей диалогов
✅ Очистка ответов от технических артефактов
✅ Полностью локальное развёртывание (без API-ключей и внешних сервисов)
