Название проекта

«Публичный календарь событий с админ-панелью»

2. Краткое описание 

Разработал полноценное веб-приложение для публикации мероприятий организации. Администратор через удобную панель создаёт события с картинками, пользователи видят календарь с возможностью скачать событие в .ics и поделиться ссылкой. Реализована адаптивная вёрстка под мобильные устройства. Всё работает локально через localStorage, без бэкенда. Проект задеплоен на Vercel.

3. Технологический стек

Деплой	Git + Vercel
Адаптив	CSS Media Queries
Инструменты	VS Code, Chrome DevTools

4. Функциональность (что умеет проект)

Публичный календарь (index.html):

Отображение событий по месяцам
Переключение между месяцами (стрелки)
Подсветка выходных и праздников
Подсветка текущего дня
Карточки событий с миниатюрами (загружаются через админку)
Модальное окно с полной информацией о событии
Скачать событие в формате .ics (для импорта в Google/Apple календарь)
Поделиться ссылкой на событие (копирование в буфер)
Админ-панель (admin.html):

Добавление событий с валидацией
Загрузка картинок (base64, без внешних сервисов)
Редактирование событий
Удаление событий
Экспорт всех событий в JSON (бэкап)
Импорт из JSON

# Публичный календарь событий

Веб-приложение для публикации мероприятий организации.

## Возможности

- 📅 Просмотр событий по месяцам
- 🖼️ Загрузка картинок через админ-панель
- 📥 Скачать событие в .ics (Google/Apple календарь)
- 🔗 Поделиться ссылкой на событие
- ✏️ CRUD операции через админ-панель
- 📱 Адаптивная вёрстка под телефон

## Технологии

- HTML5 / CSS3 / JavaScript
- localStorage (хранение данных)
- Vercel (деплой)
