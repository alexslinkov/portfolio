# Портфолио: Telegram AI‑агент с голосовым управлением и интеграцией Google Календаря

## 📌 О проекте
Разработан полностью автономный Telegram‑бот, который работает 24/7 на удалённом сервере.  
Бот понимает голосовые и текстовые команды, взаимодействует с Google Calendar и Google Tasks, использует LLM через Groq API для обработки естественного языка.

## 🎯 Задачи, которые решает бот
- Создание, просмотр и удаление событий в Google Календаре  
- Создание задач в Google Tasks  
- Ответы на вопросы пользователя с помощью ИИ  
- Распознавание голосовых сообщений в Telegram  
- Автономная работа без участия пользователя  

## 🛠 Стек технологий
- **Python 3.12** — основной язык  
- **Telegram Bot API** — интерфейс общения  
- **Groq API (LLaMA 3.1 8B)** — бесплатная языковая модель  
- **Google Calendar API / Tasks API** — интеграция с календарём и задачами  
- **Google Speech Recognition** — распознавание голоса  
- **Service Account (OAuth)** — безопасная авторизация Google на сервере  
- **Ubuntu VPS** — серверное размещение  
- **Git / GitHub** — контроль версий и CI/CD  
- **Systemd + nohup** — управление процессом в фоне  

## 🔄 Архитектура и workflow
1. Пользователь отправляет голосовое или текстовое сообщение боту в Telegram  
2. Бот скачивает аудио, конвертирует его (ogg → wav) и распознаёт речь  
3. Распознанный текст или обычное сообщение передаётся в LLM (Groq)  
4. LLM анализирует запрос и формирует JSON с указанием нужного инструмента (`calendar`, `tasks`, `chat`)  
5. Бот выполняет вызов соответствующего Google API и возвращает результат пользователю  

Вся система работает на VPS, не требует участия пользователя и не привязана к его локальному компьютеру.

|---------|------------------|
| Создать встречу | «Запланируй встречу с Петей на пятницу в 15:00» |
| Показать события | «Что у меня на завтра?» |
| Удалить встречу | «Удали встречу с Петей» |
| Создать задачу | «Добавь задачу купить молоко» |
| Голосовая команда | записать голосовое сообщение в Telegram |
| Общий вопрос | «Расскажи о современных технологиях ИИ» |

## 📈 Результат и ценность
- Полностью рабочий и отказоустойчивый сервис, работающий 24/7  
- Пользователь получает **голосового ассистента** в своём Telegram, интегрированного с его Google‑аккаунтом  
- Бот **экономит время** на планировании и управлении задачами  
- Проект может быть легко масштабирован (добавление новых инструментов, смена LLM, подключение к другим API)  

## 🔐 Безопасность
- Все секреты (токены Telegram, Groq API, ключи Google) хранятся в файле `.env`, который исключён из Git  
- Используется Google Service Account — авторизация на сервере без браузера  
- Доступ к серверу только по SSH
